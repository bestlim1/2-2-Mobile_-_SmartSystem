# Squat Posture Correction — 스쿼트 자세 교정 시스템

카메라 영상에서 관절 각도를 계산해 올바른 자세의 스쿼트만 횟수로 세고, 웹 페이지로 실시간 영상과 운동 결과를 보여 주는 개인 프로젝트입니다. 노트북 웹캠으로 동작하는 버전을 먼저 만들었고, 라즈베리파이에 카메라·LED·센서를 연결한 버전으로 완성했습니다.

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 프로젝트 (2024년 9월 ~ 12월) |
| 하드웨어 | Raspberry Pi, 카메라, LED 2개, 온습도 센서(HTU21D), 초음파 센서 |
| 소프트웨어 | Python, Flask, MediaPipe Pose, OpenCV, HTML · CSS · JavaScript |
| 문서 | [최종 보고서 (PDF, 56쪽)](docs/final-report.pdf) |

## 동작 방식

1. 웹 페이지에서 운동을 시작하면 카운트다운 뒤 카메라 스트리밍이 시작됩니다.
2. MediaPipe Pose로 어깨, 엉덩이, 무릎, 발목 좌표를 얻어 무릎 각도와 상체 기울기를 계산합니다.
3. 무릎 각도가 150° 이상인 선 자세에서 95° 이하로 내려가면 1회로 셉니다.
4. 1회가 인정되면 비프음이 울리고, 화면에 그려지는 관절 선이 빨강에서 초록으로 바뀝니다.
5. 목표 횟수를 채우면 스트리밍을 멈추고 운동 결과 페이지로 넘어갑니다.
6. 운동 영상은 파일로 저장합니다.

### 노트북 웹캠 버전 (`app.py`)

- 무릎 각도, 상체 각도, 스쿼트 횟수를 영상 위에 한글로 표시합니다.
- 무릎이 발목보다 앞으로 많이 나가면 횟수로 세지 않습니다.
- 자세에 따라 안내 문구를 보여 줍니다: "무릎 굽히기", "엉덩이를 뒤로 더 빼세요", "스쿼트 자세를 잡으세요", "무릎을 너무 펴면 안됩니다."
- 10회를 채우면 종료하고, 운동 영상(MP4)과 횟수를 `static/` 아래에 저장합니다.

개발 중간 단계의 코드여서 페이지 사이 이동 일부가 맞지 않습니다. 벤치프레스·풀업 페이지는 화면 틀만 있습니다. 완성된 흐름은 보고서의 라즈베리파이 버전을 기준으로 봐 주세요.

### 라즈베리파이 최종 버전 (보고서 수록)

노트북 버전에서 다음이 달라졌습니다.

- **LED**: 운동 중에는 빨강 LED가 켜져 있고, 1회가 인정되면 초록 LED가 1초 동안 켜집니다.
- **센서**: 온습도 센서와 초음파 센서 값을 `/sensor-data` 주소로 제공하고, 결과 페이지에 운동 환경의 온도와 습도를 보여 줍니다.
- **페이지 전환**: 목표 횟수를 채우면 Socket.IO 이벤트로 결과 페이지로 이동합니다.
- **목표 횟수**: 기본 5회이며 결과 페이지에서 다음 목표를 설정합니다.
- **영상 저장**: AVI(XVID)로 저장하고 결과 페이지에서 내려받습니다.

| 부품 | 연결 |
| --- | --- |
| LED (빨강 / 초록) | GPIO5 / GPIO6 |
| 초음파 센서 | GPIO16, GPIO20 |
| 온습도 센서 | I2C (SDA1, SCL1) |

## 실행 방법 (노트북 웹캠 버전)

비프음에 `winsound`를 쓰기 때문에 Windows에서만 동작합니다.

```bash
pip install -r requirements.txt
python app.py
```

- 한글 표시용 글꼴 파일 `NanumGothic.ttf`를 `app.py`와 같은 폴더에 두어야 합니다.
- 실행한 뒤 브라우저에서 `http://127.0.0.1:5000/timer_squat/`을 엽니다.

## 해결한 문제

웹 페이지에 카메라 스트리밍과 관절 랜드마크, 텍스트를 함께 출력하는 과정에서 어려움이 있었습니다. Flask의 `static`과 `templates` 디렉터리 구조로 정적 파일과 페이지를 분리해 해결했습니다.
